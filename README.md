## 简介

ZMusic Mod 是 ZMusic 的 Minecraft 客户端模组，采用多加载器架构，支持 Fabric、NeoForge 和 Forge 三条版本线。

## 版本矩阵

| 构建线 | 加载器 | Minecraft 版本 |
|--------|--------|----------------|
| Modern | Fabric | `1.16.5`、`1.21.8`、`26.1` |
| Modern | NeoForge | `1.21.1` |
| Legacy | Forge | `1.7.10`、`1.12.2` |

## 开发

```bash
# 初始化环境
mise install

# 构建
mise run build
```
